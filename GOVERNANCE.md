# Governance

CCOS Enterprise is maintained under a single-maintainer governance model.

The sole active authorized human contributor, maintainer, and decision-maker is **CHECKUPAUTO / MEMOPERF**. These are two accepted aliases for the same human identity.

Historical Git metadata can contain former display names. Those historical names do not grant current contributor status; the repository author policy accepts them only inside the explicitly frozen pre-cutover history.
